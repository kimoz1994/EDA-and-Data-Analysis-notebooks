# EDA & Data Analysis Notebooks

This repository showcases a collection of exploratory data analysis (EDA) and data analysis projects using Python and Jupyter Notebooks. Each notebook demonstrates data cleaning, visualization, statistical analysis, and actionable insights.

## Notebooks

| Notebook | Description |
| --- | --- |
| [european-soccer-analysis.ipynb](./european-soccer-analysis.ipynb) | EDA and analysis of European soccer data exploring team performance, home/away trends, and match statistics. |
| [Gross-Margin-Analysis.ipynb](./Gross-Margin-Analysis.ipynb) | Product-level profitability analysis examining gross margins to identify key drivers and opportunities. |
| [Monthly-Sales-Seasonality-Modeling.ipynb](./Monthly-Sales-Seasonality-Modeling.ipynb) | Time series analysis and modeling to detect and forecast monthly sales seasonality patterns. |

## Tools Used

- Python
- Jupyter Notebooks
- Pandas
- NumPy
- Matplotlib & Seaborn
- Statsmodels (as applicable)

## Getting Started

1. Clone the repository: `git clone https://github.com/kimoz1994/EDA-and-Data-Analysis-notebooks.git`
2. Install dependencies: `pip install -r requirements.txt` (if available)
3. Launch Jupyter: `jupyter lab` or `jupyter notebook`
4. Open any notebook and run cells sequentially
